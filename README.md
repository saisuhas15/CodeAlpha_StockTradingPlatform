# 📈 Stock Trading Platform

### CodeAlpha Java Programming Internship Project

A console-based Stock Trading Platform developed using Java. This application simulates a stock market environment where users can buy and sell stocks, manage their portfolios, track wallet balances and calculate investment profit and loss.

## 🚀 Features

- User Registration
- Stock Market Data Display
- Buy Stocks
- Sell Stocks
- Portfolio Management
- Virtual Wallet Management
- Transaction History
- Profit and Loss Calculation
- Stock Search
- Stock Price Updates
- Automatic Data Saving
- Automatic Data Loading

## 🛠️ Technologies Used

- Java 21
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Java Serialization
- File Handling
- VS Code
- Git and GitHub

## ⚙️ Installation and Execution

### Prerequisites

- Java JDK 21
- Visual Studio Code (or any Java IDE)

### Step 1: Clone Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### Step 2: Navigate to Project Folder

```bash
cd CodeAlpha_StockTradingPlatform
```

### Step 3: Compile Java Files

```bash
javac -d out src/*.java
```

### Step 4: Run Application

```bash
java -cp out Main
```
